## 🧩 About

**The Front Unlocker** is a curated list of The Front open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, map radar
- **Quality-of-Life Helpers** — loot catalog, crafting notes, inventory manager
- **Research Notes** — base layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Tracker — monitor resources and loot spawns
- Map Radar — visualize nearby points of interest
- Loot Helper — highlight containers and drops
- Crafting Notes — organize recipes and materials

### Wallhack
- Base Layout Planner — plan and share base designs
- Waypoint Manager — set custom waypoints
- Day/Night Indicator — track time of day
- Threat Radar — show nearby threats

### Aimbot
- Inventory Sorter — auto-sort items
- Quick Slots — assign items to hotkeys
- Config Profiles — save and load settings
- Overlay HUD — customizable on-screen info
